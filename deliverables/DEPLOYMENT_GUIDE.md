# SM SADI — মোবাইল দিয়ে Blogger (`Edit HTML`) + HopWeb + Telegram MiniApp গাইড

আপনার সুবিধার জন্য **HTML + CSS + JavaScript + JSON Config + `worker.js` + 9-Slot Monetag Ad Loop (`11924593`, `11924529`, `11924571`) + 10s Auto-Close Ad Overlay + Gold Coins + 1-10m Dropdown + Stop Limit Box (`1000`)**—সবকিছু **একটিমাত্র `index.html`** ফাইলের ভেতরেই দেওয়া হয়েছে।

---

## ধাপ ১: Blogger.com-এ Theme -> Edit HTML থেকে বসিয়ে রান করার নিয়ম (আপনার ভিডিও অনুযায়ী)
১. অ্যাপের একদম উপরে থাকা **`📋 Copy All HTML (Blogger Edit HTML)`** বাটনে ১ বার চাপ দিন (সম্পূর্ণ `index.html` কোড কপি হয়ে যাবে)।
২. আপনার মোবাইলের ব্রাউজারে **Blogger.com**-এ যান এবং বাম পাশের মেনু থেকে **Theme**-এ ক্লিক করুন।
৩. **CUSTOMIZE** বাটনের ডান পাশের ড্রপডাউন তীর (**`▼`**) বাটনে চাপ দিন।
৪. তালিকা থেকে **`Switch to first-generation Classic theme`** সিলেক্ট করুন এবং **`SWITCH WITHOUT A BACKUP`** চাপুন।
৫. আবার **`▼`** বাটনে চাপ দিয়ে **`Change Navbar`** থেকে **`Off`** সিলেক্ট করে **Save** করুন।
৬. এরপর **`EDIT HTML`** বাটনে চাপ দিন, ভেতরের আগের সব কোড মুছে ফেলুন (Select All -> Delete), এবং কপি করা **`index.html`** কোডটি **Paste** করে ডান পাশের উপরে **Save (💾)** আইকনে চাপ দিন।
৭. এবার **View blog**-এ ক্লিক করলেই আপনার `.blogspot.com` লিংকে সম্পূর্ণ **SM SADI Automated AI Trading MiniApp** চালু হয়ে যাবে!

---

## ধাপ ২: HopWeb অ্যাপে রান করার নিয়ম
১. স্ক্রিনের উপরের **`📄 কোড দেখুন (View Code)`** -> **`📥 Download index.html`** এবং **`🖼️ smbg.png`** বাটনে ক্লিক করে ফাইল দুটি ডাউনলোড করুন।
২. **HopWeb** অ্যাপে একই ফোল্ডারে `index.html` এবং তার বাহিরে `smbg.png` রেখে **Run (▶️)** চাপলেই সাথে সাথে রান হবে।

---

## ধাপ ৩: Telegram Bot (`/start` -> `🚀 Open SM AI TRADER` -> `⛏️ MiniApp`)
১. আপনার Blogger লিংক (`https://your-name.blogspot.com`) ওপেন করে উপরের **`⚡ Sync /start Bot`** বাটনে একবার ক্লিক করুন।
২. সাথে সাথে আপনার টেলিগ্রাম বট (`8585116863:...`)-এ `/start` দিলে **`🚀 Open SM AI TRADER`** বাটন চলে আসবে এবং ক্লিক করলেই মিনিমাইজ ও ম্যাক্সিমাইজ সুবিধাসহ **⛏️ MiniApp** হিসেবে ওপেন হবে!
